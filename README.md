# Megtrack Website

The Megtrack website is built with Next.js App Router, React, and TypeScript.

## Project structure

- `src/app/` contains the root layout, global styles, and route segments.
- `src/components/` is for reusable UI components.
- `public/` contains static assets served from the site root.
- Root configuration files such as `next.config.ts`, `tsconfig.json`, and
  `eslint.config.mjs` stay at the project root.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Validation and production

```bash
npm run lint
npm run build
npm run start
```
